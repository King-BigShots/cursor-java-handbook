# Codex for Open Source 申请前检查清单

按顺序完成下列项。全部打勾后再提交[官方表单](https://openai.com/zh-Hans-CN/form/codex-for-oss/)。

## 1. ChatGPT 账号

- [ ] 已在 https://chatgpt.com 注册并可以正常登录
- [ ] 记住登录邮箱，**申请表邮箱必须与该邮箱一致**
- [ ] 如需 Pro 权益，确认账号未被限制或封禁

## 2. OpenAI Organization ID（表单必填）

- [ ] 打开 https://platform.openai.com 并用与 ChatGPT **相同或关联**的账号登录
- [ ] 进入 **Settings → Organization**（或表单中的「点击此处查找」链接）
- [ ] 复制 Organization ID，格式类似：`org-xxxxxxxxxxxxxxxx`
- [ ] 将 ID 临时保存在本机安全位置（不要提交到公开 issue）

## 3. GitHub 账号与公开资料

- [ ] 已在 https://github.com 注册
- [ ] **Settings → Public profile**：个人资料可见性为 **Public**
- [ ] 头像、简介（Bio）已填写（便于审核识别真实用户）
- [ ] 记下你的 GitHub 用户名：`________________`

## 4. 公开仓库（本仓库推送到 GitHub 后）

- [ ] 在 GitHub 新建仓库，名称建议：`cursor-java-handbook-zh`（或与本地文件夹一致）
- [ ] 可见性选择 **Public**
- [ ] 按 [GITHUB_SETUP.md](./GITHUB_SETUP.md) 完成 `git push`
- [ ] 在浏览器打开仓库 URL，确认 README 正常显示
- [ ] 你是该仓库的 **Primary maintainer**（仓库在你账号下）

## 5. 提交前自检

- [ ] 未编造 star 数、下载量或维护者身份
- [ ] 已阅读 [Codex for Open Source 项目条款](https://developers.openai.com/codex/codex-for-oss-terms)
- [ ] 已准备好 [APPLICATION_DRAFT.md](./APPLICATION_DRAFT.md) 中的文案（复制到表单）
- [ ] 理解：**提交不保证通过**，结果以 OpenAI 邮件通知为准
