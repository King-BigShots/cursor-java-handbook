# 提交官方申请表 — 逐步指南

表单地址：**https://openai.com/zh-Hans-CN/form/codex-for-oss/**

提交前请完成 [APPLY_CHECKLIST.md](./APPLY_CHECKLIST.md) 全部项。

## 逐步填写

| 步骤 | 表单字段 | 你怎么做 |
|------|----------|----------|
| 1 | 姓氏 / 名字 | 填写真实姓名（与常用身份一致即可） |
| 2 | 电子邮箱 | **必须与 ChatGPT 登录邮箱相同** |
| 3 | GitHub 用户名 | 你的公开用户名，确认 Profile 为 Public |
| 4 | GitHub 代码仓库 URL | 例如 `https://github.com/你的用户名/cursor-java-handbook-zh` |
| 5 | 维护者角色 | 个人仓库选 **主要维护者** |
| 6 | 为何符合要求 | 复制 [APPLICATION_DRAFT.md](./APPLICATION_DRAFT.md) 中文段，按实修改 star/维护描述 |
| 7 | 感兴趣项 | 需要 API 则勾选；仅需 Pro 可只选相关项 |
| 8 | OpenAI Organization ID | 从 platform.openai.com 复制 `org-...` |
| 9 | API 额度用途 | 复制 APPLICATION_DRAFT 中「API 额度用途」段 |
| 10 | 其他说明 | 可选，复制「其他说明」段 |
| 11 | 提交 | 勾选同意项目条款后 Submit |

## 提交后

- 留意邮箱（含垃圾邮件），主题可能来自 OpenAI
- **未收到邮件 ≠ 立刻拒绝**，滚动审核可能需数天至数周
- 勿重复用多个账号提交同一仓库

## 通过后（若入选）

- 按邮件说明激活 ChatGPT Pro / Codex
- API 额度若有单独指引，遵守条款仅用于本仓库维护工作流
- 权益不可转让、出售（见官方 Program Terms）
