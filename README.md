# cursor-java-handbook-zh

中文 **Java 入门** 与 **Cursor IDE** 实操手册 — 面向零基础自学者，免费开源。

## 项目用途

| 模块 | 说明 |
|------|------|
| [notes/java](./notes/java/) | Java 环境、语法、常见错误说明 |
| [notes/cursor](./notes/cursor/) | Cursor 安装、快捷键、与 Java 项目配合 |
| [templates](./templates/) | Issue 分类、维护者检查清单 |
| [docs](./docs/) | 申请 Codex OSS、GitHub 发布与维护记录 |

## 快速开始

1. 克隆本仓库：`git clone https://github.com/YOUR_USERNAME/cursor-java-handbook-zh.git`
2. 按顺序阅读 `notes/java/01-环境搭建.md`
3. 安装 [Cursor](https://cursor.com) 后阅读 `notes/cursor/01-安装与登录.md`
