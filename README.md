# cursor-java-handbook

中文 **Java 入门** 与 **Cursor IDE** 学习笔记，面向零基础自学者，免费开源。

## 内容概览

| 模块 | 说明 |
|------|------|
| [notes/java](./notes/java/) | Java 环境、语法入门 |
| [notes/cursor](./notes/cursor/) | Cursor 安装与常用操作 |
| [templates](./templates/) | Issue 分类与维护清单 |
| [docs](./docs/) | 路线图与更新记录 |

## 快速开始

1. 克隆仓库：

```bash
git clone https://github.com/King-BigShots/cursor-java-handbook.git
```

2. 阅读 [notes/java/01-环境搭建.md](./notes/java/01-环境搭建.md)
3. 安装 [Cursor](https://cursor.com) 后阅读 [notes/cursor/01-安装与登录.md](./notes/cursor/01-安装与登录.md)
