# Codex 基本使用与权限

## 两种常见用法

### 1. 纯对话

不选本地文件夹时，Codex 主要做问答、查资料、写方案，类似 ChatGPT，但更适合开发场景。

示例：

```text
列出学习 Java 的前四周学习计划，每周不超过 3 个目标。
```

### 2. 绑定本地文件夹（工作区）

在左侧选择 **项目 / 文件夹**，Codex 可在该目录内读文件、改文件、执行终端命令。

适合：整理笔记、分析项目结构、批量重命名、写文档等。

示例：

```text
阅读 notes/java 目录下的 Markdown，列出已有章节标题并建议下一篇写什么。
```

## 权限模式（重要）

选定工作区后，对话框底部通常有三种权限级别（名称以应用内为准）：

| 模式 | 特点 | 适合人群 |
|------|------|----------|
| 默认权限 | 改工作区文件前会询问 | 新手、怕误删文件 |
| 自动审查 | 由系统自动审核部分操作 | 日常省心 |
| 完全访问 | 少弹确认，效率高 | 熟悉备份、能接受风险 |

**建议**：第一次用本地文件夹选「默认权限」；熟悉后再考虑自动审查。

## 文件操作小实战

对工作区执行：

```text
统计 notes 目录下有多少个 .md 文件，按子文件夹分组列出文件名。
```

观察 Codex 是否通过终端或读文件完成任务。完成后在 Git 或资源管理器中核对结果，**不要盲信输出**。

## 删除与越界操作

若要求删除工作区外的路径，Codex 应拒绝或要求确认。这是安全设计，不要强行给「完全访问」去删系统目录。

## 斜杠命令速查

| 命令 | 用途 |
|------|------|
| `/status` | 查看额度与上下文占用 |
| `/压缩` | 对话过长时压缩历史，聚焦新任务 |

更多命令以应用内 `/` 提示列表为准。
