# 技能、插件与进阶入口

Codex 可通过 **插件** 扩展能力，通过 **Skills（技能）** 让 AI 按固定流程处理某类任务。

## 插件

在左侧 **插件** 面板可浏览、安装，例如：

| 类型 | 典型用途 |
|------|----------|
| 部署类 | 将静态站点发布到托管平台 |
| 浏览器类 | 自动打开网页、截图、填表（需注意权限） |
| GitHub 类 | 查看仓库、协助 PR 流程 |

安装第三方插件前建议看清权限说明，优先选知名来源。

## Skills（技能）

技能相当于「可复用的操作说明书」。调用方式常见两种：

- 对话里输入 `$技能名` 或应用内技能选择器
- 任务匹配时自动加载，节省重复写长提示词

### 内置技能示例（以你安装的版本为准）

| 技能方向 | 能做什么 |
|----------|----------|
| 图像生成 | 根据描述生成配图、头像等 |
| 文档查询 | 结合官方文档回答问题 |
| 技能安装器 | 从社区安装其他技能 |

### 使用社区技能注意

- 优先选 star 多、来源清晰的项目
- 可把 GitHub 链接发给 Codex，让它先检查再安装
- 不明链接不要随意安装

### 自建技能思路

把反复做的流程（例如「按模板生成学习笔记章节」）封装成 `SKILL.md`，以后一句话复用。可用内置的 skill-creator 类技能辅助生成。

## MCP 是什么（了解即可）

MCP（Model Context Protocol）让 AI 连接外部工具，例如拉取最新 API 文档。入门阶段可先掌握 **Skills + 插件**；需要查最新文档时再在设置里添加 MCP 服务器。

## Browser / Computer 使用建议

| 能力 | 说明 | 建议 |
|------|------|------|
| 浏览器操控 | 自动打开页面、点击 | 适合抓取公开页、截图；多试几次可能才稳定 |
| 电脑操控 | 控制桌面应用 | 门槛高、耗额度，能用命令行/浏览器解决则优先不用 |

## 上下文管理

- 单对话上下文有限，长聊会占满 → 用 `/压缩` 或开新对话
- **全局指令**：设置 → 个性化（影响所有项目）
- **项目 AGENTS.md**：放在项目根目录，仅该项目生效

可在项目根添加 `AGENTS.md`，例如：

```markdown
# 项目约定
- 回复使用简体中文
- 修改 notes 下的 md 时保持章节编号风格一致
- 不删除 LICENSE 与 README
```

## 和 Cursor 怎么选

| 工具 | 更像什么 | 适合 |
|------|----------|------|
| Codex | AI 助理型应用，门槛低 | 不想折腾 IDE、快速试想法 |
| Cursor | AI + 代码编辑器 | 日常写 Java、看 diff、改多文件 |

两者可以配合：本仓库笔记在 Cursor 里编辑，用 Codex 做规划、生成初稿、整理文档。
