# Codex 安装与入门

Codex 是 OpenAI 推出的 AI 编程助手，有桌面应用和命令行等形式。本篇帮助零基础同学完成安装并发出第一条指令。

> 延伸阅读（结构参考）：[Codex 零基础实战教程 - 编程导航](https://www.codefather.cn/post/2059269098432385025)

## 需要什么

| 准备项 | 说明 |
|--------|------|
| ChatGPT 账号 | 用于登录 Codex |
| 系统 | Windows 或 macOS（Linux 可用 Codex CLI） |
| 网络 | 能访问 OpenAI 服务 |

免费账号可体验，日常开发若额度不够可考虑 Plus 等订阅（以官网当前政策为准）。

## 下载安装

1. 打开官方入门页：https://chatgpt.com/codex/get-started/
2. 下载对应系统的 Codex 应用并安装
3. 使用 ChatGPT 账号登录

## 界面大致分区

| 区域 | 作用 |
|------|------|
| 左侧栏 | 对话列表、插件、自动化等入口 |
| 中间 | 主对话区，输入提示词与查看回复 |
| 设置 | 额度、工作模式、权限等 |

## 第一条指令

在对话框输入：

```text
用三句话介绍 Java 是什么，面向完全零基础读者。
```

能正常回复说明安装与登录成功。

## 工作模式建议

在 **设置** 中可将模式切换为「适用于编程」，回复会更偏开发与代码场景（具体名称以应用内显示为准）。

## 查看额度

- 设置 → 剩余额度：查看 5 小时 / 本周配额
- 对话中输入 `/status`：查看当前上下文与额度（斜杠命令）
