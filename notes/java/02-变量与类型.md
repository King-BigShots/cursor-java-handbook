# 变量与基本类型

## 变量是什么

变量像一个带标签的盒子，用来存放数据。使用前要先声明类型和名字。

```java
int age = 18;
String name = "小明";
```

## 常见基本类型

| 类型 | 示例 | 说明 |
|------|------|------|
| `int` | `42` | 整数 |
| `double` | `3.14` | 小数 |
| `boolean` | `true` | 真 / 假 |
| `char` | `'A'` | 单个字符 |
| `String` | `"hello"` | 字符串（引用类型，初学者可先当文本用） |

## 命名建议

- 使用英文小驼峰：`studentName`、`totalScore`
- 见名知意，避免 `a1`、`tmp2` 这类难懂名字
- 常量可用全大写：`MAX_SIZE = 100`

## 类型转换

小范围赋给大范围通常自动完成：

```java
int n = 10;
double d = n;   // d 为 10.0
```

大范围赋给小范围需强制转换，可能丢失精度：

```java
double pi = 3.14;
int x = (int) pi;   // x 为 3
```

## 练习

1. 声明两个 `int` 变量表示语文、数学分数，打印平均分。
2. 用 `boolean` 表示是否及格（平均分 ≥ 60）。
