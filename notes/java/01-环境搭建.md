# Java 环境搭建（Windows）

面向第一次安装 Java 的初学者。

## 需要准备的软件

| 软件 | 用途 | 下载 |
|------|------|------|
| JDK 17+ | 运行与编译 Java | [Adoptium](https://adoptium.net/) 或 Oracle JDK |
| Cursor / VS Code | 写代码的编辑器 | [cursor.com](https://cursor.com) |

## 安装 JDK

1. 下载 Windows x64 安装包并运行
2. 安装完成后打开 **PowerShell**，输入：

```powershell
java -version
javac -version
```

若显示版本号（如 `17.x`），说明安装成功。

## 配置 JAVA_HOME（推荐）

1.  Win + R → `sysdm.cpl` → **高级** → **环境变量**
2.  新建系统变量：
    - 变量名：`JAVA_HOME`
    - 变量值：JDK 安装目录，例如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.x-hotspot`
3.  编辑 `Path`，新增：`%JAVA_HOME%\bin`
4.  重新打开终端，再次执行 `java -version`

## 第一个程序

在任意空文件夹创建 `Hello.java`：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

编译与运行：

```powershell
javac Hello.java
java Hello
```

屏幕输出 `Hello, Java!` 即表示环境可用。

## 常见问题

**'java' 不是内部或外部命令**  
→ 检查 `Path` 是否包含 `%JAVA_HOME%\bin`，并重启终端。

**版本号不对**  
→ 可能装了多个 JDK，用 `where java` 查看实际使用的路径。
