# Cursor 常用快捷键（Windows）

默认键位可能与 VS Code 相近；若冲突可在 **File → Preferences → Keyboard Shortcuts** 中搜索修改。

## 编辑

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + S` | 保存当前文件 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + /` | 行注释切换 |
| `Alt + ↑` / `Alt + ↓` | 上/下移动当前行 |
| `Ctrl + D` | 选中下一个相同单词 |

## 导航

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + P` | 快速打开文件 |
| `Ctrl + Shift + F` | 全项目搜索 |
| `F12` | 跳转到定义（Java 需语言服务就绪） |
| `Alt + ←` / `Alt + →` | 后退 / 前进光标位置 |

## 终端

| 快捷键 | 作用 |
|--------|------|
| `` Ctrl + ` `` | 显示/隐藏集成终端 |
| `Ctrl + Shift + `` ` `` | 新建终端 |

在终端中可运行 `javac`、`java` 与 Maven 命令。

## AI 相关（以 Cursor 当前版本为准）

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + L` | 打开 Chat 面板（常见默认） |
| `Ctrl + I` | 行内编辑 / Composer（版本可能不同） |

若键位无效，在命令面板 `Ctrl + Shift + P` 搜索 `Cursor` 查看实际绑定。

## 学习建议

先熟练 `Ctrl + S`、`Ctrl + P` 和终端，再逐步使用 AI 功能，避免过度依赖自动生成代码。
