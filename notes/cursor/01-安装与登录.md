# Cursor 安装与登录

Cursor 是基于 VS Code 的 AI 代码编辑器，适合配合 Java 学习使用。

## 下载安装

1. 打开 https://cursor.com 下载 Windows 版本
2. 按向导安装，首次启动可选择导入 VS Code 配置（可选）

## 登录账号

1. 点击左下角账户图标或菜单 **Sign In**
2. 使用邮箱或 GitHub / Google 登录
3. 登录后可使用 AI 对话与 Agent 功能（具体权益以 Cursor 账户为准）

## 打开 Java 项目文件夹

1. **File → Open Folder**
2. 选择包含 `.java` 文件的文件夹
3. 若提示安装 **Extension Pack for Java**，建议安装以便高亮与运行

## 推荐设置（初学者）

| 设置项 | 建议 |
|--------|------|
| 自动保存 | File → Auto Save → afterDelay |
| 字体大小 | Settings 搜索 `Font Size` → 16～18 |
| 中文界面 | 安装 Chinese Language Pack 扩展（可选） |

## 与 AI 协作的注意点

- 提问时说明语言（Java）与错误完整报错信息
- AI 生成的代码需自己运行验证，不要直接照抄不理解的代码
- 学习阶段优先理解示例，再使用 Agent 自动改多文件
