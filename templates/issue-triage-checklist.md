# Issue 分类检查清单（维护者用）

处理新 issue 时可按此流程操作，也可配合 API 生成草稿后人工确认。

## 1. 快速分类

| 标签建议 | 适用情况 |
|----------|----------|
| `documentation` | 文档错误、链接失效、表述不清 |
| `enhancement` | 希望新增章节或示例 |
| `question` | 使用疑问，不一定要改仓库 |
| `good first issue` | 适合新人小改（错别字等） |

## 2. 必填核对

- [ ] 是否说明具体文件路径（如 `notes/java/01-环境搭建.md`）
- [ ] 是否提供操作系统版本（Windows 10/11）
- [ ] 若是 Java 运行错误，是否附带完整报错

## 3. 回复模板（可复制修改）

```text
感谢反馈！已确认问题在 [章节/文件]。
计划在 [时间范围] 内更新，欢迎 PR。
```

## 4. 关闭条件

- 修复已合并并出现在 CHANGELOG
- 提问已解答且无需改文档
- 重复 issue 可链接到主 issue 后关闭
